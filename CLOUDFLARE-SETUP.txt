ENQUIRY EMAIL SETUP:
The enquiry form does not open the visitor's Gmail/Outlook. It submits to the Cloudflare Pages Function.
Set these as Cloudflare Pages production environment variables/secrets:
- RESEND_API_KEY = your Resend API key (keep secret)
- ENQUIRY_TO = css.serviceinfo@gmail.com (optional; this is the default)
- ENQUIRY_FROM = a verified sender such as CSS Service Solution <noreply@your-verified-domain>

IMPORTANT:
Do not publish API keys/secrets in GitHub.
If the Resend sender domain has not been verified yet, configure that before testing live email delivery.
